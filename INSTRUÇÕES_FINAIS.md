## 🧮 FÓRMULAS DE CÁLCULO

### **Lucro Bruto**
```
Lucro Bruto = Preço de Venda - Preço de Custo
```

### **Taxa do Marketplace**
```
Taxa = Preço de Venda × (% da Categoria / 100)
```

### **Lucro Líquido**
```
Lucro Líquido = Lucro Bruto - Taxa - Frete
```

### **Margem de Lucro (%)**
```
Margem = (Lucro Líquido / Preço de Venda) × 100
```

### **Exemplo Prático**
```
Categoria: Eletrônicos (12%)
Custo: R$ 100,00
Venda: R$ 200,00
Frete: R$ 10,00

Lucro Bruto = 200 - 100 = R$ 100,00
Taxa (12%) = 200 × 0,12 = R$ 24,00
Lucro Líquido = 100 - 24 - 10 = R$ 66,00
Margem = (66 / 200) × 100 = 33%
```
